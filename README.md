## 名字来历 ##

最早16-17年的时候开始用抖音，大抵是用名字缩写上网的（我的真名有点不好意思公开），其实也有点记不清了。后来20年左右疫情特殊时期，那段时间互联网发展飞快，我就用了一个当时小学大家叫我的名字：xiaowei

再后来就是看到[名游社](https://space.bilibili.com/64116958?spm_id_from=333.337.0.0 "Bilibili")和影子大哥玩AmongUs，后来影子大哥又去做[太空杀](https://www.spaceparty.cn "太空杀")的视频，于是我也加入了太空杀这个家庭，取的名字就是**太空杀xiaowei**

再后来那个账号丢了，我另外开了一个小号，又叫做**太空杀dawei**，一大一小，很匀称【赞】

转折点在22年的一个暑假，当时华强买瓜的二创很多（现在也是），我就想到了“吃瓜群众”，感觉有点太平淡了，然后脑子突然一抽：**食瓜之众**！！！

于是乎，这个名字一直用到了26年...~~（值得注意的是，之所以只用到26年，是因为我这篇写的日期是26年）~~

期间也换过很多名字，比如“食瓜之众”“食瓜之众是歌姬”

如果有细心的人应该会注意到我之前快手账号（很抱歉，已经注销了）用过 ***Lv116 Vigo*** 的名字，这个是我初中时候的微信名字，感觉好尬...

~~***“Lv116”这个名字跟知名品牌LV无关，根据后面的数字可知，这个名字来源于元素周期表第116位元素“鉝、𫟷”***~~
